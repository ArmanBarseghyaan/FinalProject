# 🎮 Final Project - Game Hub (Игровой Центр)

Сборник аркадных и сетевых Java-игр, объединенных единым графическим (JavaFX) и консольным (CLI) лаунчером. Проект написан на **Java 17** с использованием сборщика проектов **Maven**.

---

## 🚀 Входящие в состав игры

1. 🏎️ **Гонки (Racing Game)**
   * Динамичный 2D-автосимулятор.
   * Настройка уровней сложности (*EASY*, *MEDIUM*, *HARD*).
   * Механики: нитро-ускорение, монетный сбор, объезд масляных пятен и конусов.

2. ⚓ **Морской Бой (Sea Battle)**
   * **Сетевой режим (LAN Sockets)**: Игра по локальной сети между двумя компьютерами через IP/Порт.
   * **Режим Hot-seat**: Игра для двоих на одном компьютере по очереди.
   * **CLI режим**: Консольный вариант Морского боя.
   * Звуковое сопровождение (генерация звуковых эффектов выстрелов, попаданий и промахов).

3. 🐍 **Змейка (Snake Game)**
   * Классическая аркада со змейкой и едой.
   * Динамический рост, обработка столкновений со стенами и собственным хвостом.

4. 🟡 **Пакман (Pac-Man)**
   * Полноценная реплика легендарной игры.
   * Связный лабиринт, сбор точек/энерджайзеров, ИИ призраков и оригинальные WAV-звуки.

## 🛠 Требования к системе

* **JDK**: 17 или выше (`java -version`)
* **Maven**: 3.6+ для сборки и запуска из исходников.

---

## 💻 Способы запуска программы

Вы можете запустить проект любым из удобных способов ниже:

### 1. Запуск и сборка через Maven

Находясь в корневой папке проекта (`FinalProject`):

* **Графический JavaFX-режим**:
  ```bash
  mvn clean javafx:run
  ```
  В IntelliJ IDEA также можно открыть `src/main/java/Main.java` и запустить класс `Main`
  напрямую. Проект должен быть загружен как Maven-проект, чтобы IDE подключила JavaFX-зависимости.

* **Консольный CLI-режим**:
  ```bash
  mvn clean compile exec:java -Dexec.args="--cli"
  ```

---

* **Сборка исполняемого JAR со всеми зависимостями**:
  ```bash
  mvn package
  ```
  JAR сохраняется как `target/version1_0.jar`. Запуск:
  ```bash
  java -jar target/version1_0.jar
  ```
  В Windows PowerShell используйте `java -jar .\target\version1_0.jar`.

Для автономного runtime-дистрибутива на текущей ОС можно использовать `mvn javafx:jlink`.
Цель `jlink` требует модульный проект с `module-info.java`; пока проект не модульный,
используйте `mvn clean javafx:run`.

### 2. Запуск автономных консольных игр

Некоторые игры имеют независимые консольные версии:

* **Консольные Гонки**:
  ```bash
  java -cp target/classes racing.ui.ConsoleRacingGame
  ```
* **Консольная Змейка**:
  ```bash
  java -cp target/classes com.snake.ui.ConsoleSnakeGame
  ```

## 🧪 Тестирование

Для запуска Unit-тестов логики «Морского боя», «Змейки», гонок, Pac-Man и главного CLI-запуска:

```bash
mvn test
```

├── src/                         # Исходный код проекта
│   ├── main/java/
│   │   ├── Main.java            # JavaFX-лаунчер
